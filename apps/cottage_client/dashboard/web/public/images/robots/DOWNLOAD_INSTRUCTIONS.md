# Unitree Robot Images - Download Script

This script helps download official Unitree robot images for the sales funnel.

## Images Needed:
1. **R1 Humanoid Robot**
   - Main hero shot: `/images/robots/r1-hero.jpg`
   - Side profile: `/images/robots/r1-side.jpg`
   - Action shot: `/images/robots/r1-action.jpg`

2. **Go2 Quadruped Robot**
   - Main hero shot: `/images/robots/go2-hero.jpg`
   - Side profile: `/images/robots/go2-side.jpg`
   - Action shot: `/images/robots/go2-action.jpg`

## Download Sources:
- Unitree Official Website: https://www.unitree.com/
- Unitree Shop: https://shop.unitree.com/
- Press Kit: https://www.unitree.com/media/

## Image Requirements:
- **Format**: WebP for better compression (fallback to JPG)
- **Size**: 800x600px minimum, 1200x900px preferred
- **Quality**: High quality, professional product photography
- **Background**: Clean, preferably white or transparent
- **License**: Official Unitree promotional materials

## Alternative Approach:
If official images cannot be downloaded:
1. Use high-quality screenshots from Unitree videos
2. Create professional mockups using robot specifications
3. Use stock photography with robot overlays
4. Generate 3D renders based on official specs
