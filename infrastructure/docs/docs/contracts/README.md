# Contracts

This directory contains machine-readable and human-readable contracts for the
robot fleet platform.

Files:

- `canonical-events.md`: canonical event definitions and field expectations
- `unitree-g1.twin-model-outline.md`: DTDL model outline for the Unitree G1
- `unitree-g1.json`: first-pass DTDL v3 JSON-LD model for the Unitree G1 twin
