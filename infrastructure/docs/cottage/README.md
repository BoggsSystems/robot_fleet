# Cottage Planning

This directory contains site-independent planning artifacts for the cottage
deployment. These files are designed to let the platform work proceed before
the real site measurements and operational constraints are collected.

Files:

- `site-intake-template.md`: questions and data fields to collect from the property owner
- `placeholder-graph.md`: a default graph that can be used in simulation and ADT bootstrapping
- `projection-rules.md`: how canonical events should project into the cottage twin graph
